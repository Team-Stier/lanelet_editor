Lanelet2 중심선 계산 대기

설치된 Lanelet2가 현재 경계 XYZ로 계산합니다. 편집하면 재계산하며, 계산 중·실패 시 이전 결과를 숨깁니다.

저장 중심선은 centerline 구성원이 있는 Lanelet만 표시합니다. 황색 중앙선은 경계선 레이어에 표시됩니다. Shift/Ctrl/⌘+클릭: 다중 선택

초록: 다음 · 파랑: 이전 · 노랑: 좌우 변경 허용 · 빨강 점선: 금지 · 회색 점선: 미확인. 화살표는 연결 관계를 나타내며 주행 궤적이 아닙니다.

실선점선황색 / 중앙선가상 경계복합선

선의 위치는 실제 좌표입니다. 선 두께·복합선 간격·선택 강조는 화면 심볼입니다. 복합선의 가운데 가는 선이 실제 경계 좌표입니다. 가상 경계는 도색이 없는 지도 경계입니다.

정확하게 보고 편집하기

모든 폴리곤과 점은 OSM 로컬 미터 좌표로 표시합니다. 배경도 원본 에셋의 좌표 범위에 고정됩니다. 지도·이미지를 따로 끌어 맞추는 보정은 없습니다. 위성 이미지 자체의 화소·정합 오차는 도로 메시 정밀도와 다릅니다.

  • V 선택 · 드래그 이동, 휠 확대, 클릭 선택. 겹친 면은 선택 목록 표시.
  • E 점 편집 · 점을 끌어 이동. 공유 점은 모든 연결 선이 함께 바뀝니다. 경계 선택 후 선 위 더블클릭으로 점 추가.
  • D 그리기 · 중심 경로를 순서대로 클릭한 뒤 Enter. 입력한 폭으로 새 Lanelet 생성.
  • M 측정 · 연속 클릭 거리 측정. Enter 또는 Esc로 끝내기.
  • Space 또는 휠 버튼 + 드래그 · 모든 2D 도구에서 화면 이동.
  • ⌘/Ctrl Z 실행 취소 · ⌘/Ctrl Shift Z 다시 실행 · F 전체 보기 · Esc 선택/작업 취소.

연결과 속성

분할은 공유 경계 이웃까지 함께 분할하여 같은 선 ID를 유지합니다. 연장은 끝점 ID를 공유하는 새 구간을 만듭니다. 연속 구간 합치기, 기존 경계 way 공유, 점 ID 합치기로 실제 연결도 편집할 수 있습니다. XY 스냅은 위치만 맞추며 ID를 합치지 않습니다. successor는 양쪽 끝점 ID의 일치로, 옆차선은 경계 way ID 공유로 계산합니다. 통행 가능한 차선 변경·교통 규칙 판정은 별도입니다.

저장과 내보내기

프로젝트 저장은 모든 태그·원본 요소를 포함한 JSON과 OSM을 이 폴더의 saved/에 새 파일로 만듭니다. 브라우저 임시 저장은 복구용입니다. OSM 내보내기는 현재 편집 상태를 다운로드합니다. 기존 src/hdmap의 지도는 편집 중 자동으로 덮어쓰지 않습니다.

3D와 진단

3D는 원본 높이를 확인하는 보기 모드입니다. 배경 이미지는 Z=0 평면 참조이고 실제 도로 메시에는 원본 높이가 있습니다. 편집은 2D에서 합니다. 경계 보간 중심선은 참고선이며 Lanelet2 native 중심선과 같다고 보장하지 않습니다. 원본 중심선은 편집 후에도 원본 참조로 유지됩니다.
