# Lanelet Studio

K-City 설치 에셋을 정확한 미터 좌표로 겹쳐 보는 로컬 HTML Lanelet2 편집기입니다. 프런트엔드는 HTML/CSS/JavaScript, 로컬 저장과 OSM 투영·기하 검사는 Python 서버가 담당합니다.

## 실행

```sh
./start.sh --port 8765
```

브라우저에서 **http://127.0.0.1:8765**를 여세요. `index.html`을 파일로 직접 열지 말고 서버를 통해 여세요. 서버는 localhost에만 연결됩니다. 인터넷 없이 편집할 수 있으며 Three.js도 `vendor/`에 포함됩니다.

현재 프로젝트의 `.venv`에 필요한 라이브러리를 설치했습니다. 다른 컴퓨터에서는 Python 3.11 이상으로 다음을 실행합니다.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./start.sh
```

- 3D 렌더링용 좌표 버퍼: `editor-assets/` (`prepare_assets.py`로 재생성)
- 저장된 프로젝트: `saved/`의 `.lanelet.json`과 `.osm`

복사한 최종 OSM SHA256: `848178bf24ad8cc923323822e5799ac5c82ee28e141475d91e45564cc6d5116c`.
기존 MORAI `outputs/`는 이 폴더로 이동했습니다. `src/hdmap/`에는 최종 OSM 한 파일만 복사했습니다. 실행 중인 시뮬레이터에는 접속하거나 조작하지 않았습니다.

`outputs/rddf-lanelet-comparison/`은 수정 전 지도와 공식 RDDF 비교 기록이며, 최신 지도 검증은 `outputs/lanelet-map-repair/`를 보세요. 과거 경로·해시는 원본 기록으로 보존합니다.

## 편집 기능

| 도구 | 동작 |
|---|---|
| 선택 V | Lanelet 면·경계 선택, 겹친 요소 목록, ID/원본 링크/태그 검색 |
| 점 편집 E | 공유 점 XY 드래그, XYZ 수치 편집, 경계 더블클릭으로 점 추가, 점 삭제 |
| 그리기 D | 중심 경로 클릭 후 Enter, 폭과 높이를 지정해 새 Lanelet 생성 |
| 측정 M | 연속 클릭의 실제 XY 누적 거리, Enter 고정, Esc 초기화 |
| 분할 | 공유 경계 이웃까지 같은 단면에서 함께 분할, seam 점과 경계 ID 공유 |
| 연장 | 양쪽 끝점 ID를 공유하는 새 구간, 시작/끝 선택 및 길이 지정 |
| 인접 차선 추가 | 폭(기본 3.5m)을 지정해 같은 방향의 좌/우 차선 생성, 기존 경계 공유·좌표 유지·실행 취소 지원. 이미 이웃이 있는 쪽은 생성 거부 |
| 합치기 | 정확히 연속된 독립 Lanelet 합치기. 태그 충돌·공유 이웃 등 복잡한 경우 거부 |
| 복제·반전 | XY 이동 복제, 원클릭 주행 방향 뒤집기(이웃 유지, 실행 취소 가능) |
| Lanelet 속성 | 현재 주행 방향·각도 확인, 일방/양방향 통행·제한 속도 편집, 좌/우 경계 속성 바로 열기 |
| 연결 편집 | 왼쪽/오른쪽 Lanelet 연결 버튼에서 대상 ID 지정, 같은 방향 대상의 반대편 경계 공유. 기존 경계 way ID 지정·공유, 대상 점 ID로 모든 참조 합치기 |
| 선 속성 | 한국어 종류·선 모양·색 선택, 흰 실선/흰 점선/황색 이중실선/가상 경계 프리셋, 좌/우 차선 변경 속성 편집 |
| 태그 | 모든 요소의 JSON 태그 편집, 알 수 없는 원본 태그·relation 유지 |
| 되돌리기 | 최대 100개 편집 실행 취소/다시 실행, 공유 요소 전체를 원자적으로 복원 |
| 저장 | 원본 덮어쓰기 없이 날짜가 붙은 JSON+OSM 저장, 저장 목록으로 복원 |
| 내보내기 | 현재 편집 상태의 OSM 다운로드, 원본 참조와 확장 메타데이터 보존 |
| 진단 | 누락 참조·잘못된 폴리곤·실제 중첩 면적, 항목 클릭으로 해당 요소 확대 |
| 3D | 실제 높이의 도로/도색 메시·Lanelet·참고선, 회전·이동·선택·영역 확대 |

휠은 마우스 위치 기준 확대, Space/휠 버튼+드래그는 이동입니다. F는 전체 보기, Cmd/Ctrl+Z는 실행 취소, Cmd/Ctrl+Shift+Z는 다시 실행입니다.
경계 속성은 공유 대상 Lanelet에도 적용되며 공유 대상을 표시합니다. 차선 변경의 좌/우는 경계 노드가 저장된 순서 기준이며 허용/금지/미지정을 선택합니다.
좌/우 Lanelet 연결은 선택한 Lanelet의 경계를 대상 경계로 바꾸므로 선택 형상이 바뀔 수 있습니다. 대상 좌표는 유지하며 실행 취소할 수 있습니다.
브라우저 임시 저장은 IndexedDB에 보관하고 다음 접속 때 복구를 제안합니다. 장기 보관에는 **프로젝트 저장**을 사용하세요. 저장/내보내기는 `src/hdmap`을 자동 변경하지 않습니다.

## 좌표와 표시 원칙

- EPSG:32652. 원점은 `[302595, 4124145, 0]`입니다. `X=UTM East−302595`, `Y=UTM North−4124145`.
- 2D X/Y 축척은 같습니다. 미터 격자와 거리 측정은 같은 변환을 사용하며, 배경/점/면에 별도의 보정 이동·자동 정렬을 적용하지 않습니다.
- 배경은 설치 이미지와 실제 도로·도색 메시를 정사영한 이미지입니다. 위성 이미지 자체의 해상도·정합 오차와 벡터 좌표 정밀도는 서로 다릅니다. 에디터가 영상의 절대 측량 정확도를 보장하는 것은 아닙니다.
- 노드 편집/OSM 입출력은 64비트 실수를 사용합니다. 지리좌표는 pyproj로 변환하며 local XYZ를 보존합니다. 3D GPU의 메시 버퍼는 Float32라 미터 좌표에 작은 표시 반올림이 있습니다.
- 2D 실선/점선은 저장된 경계 위의 화면 심볼입니다. 복합선의 두 획은 가독성을 위한 ±2px 간격이며 **가운데 가는 선이 실제 경계 좌표**입니다. 간격/굵기는 실제 페인트 폭이 아닙니다. 3D 복합선은 가운데 한 선의 겹친 심볼로 표시하며 실제 도색은 메시를 참고합니다.
- `Lanelet2 중심선`은 설치된 Lanelet2의 `Lanelet.centerline` 결과를 분홍색으로 표시합니다. 현재 경계 XYZ와 공유 point ID를 전달하며, 저장된 명시적 중심선이 있으면 그 값을 사용합니다. 경계 편집 시 재계산하고 계산 중·실패 시 이전 결과는 숨깁니다. 지도 파일에 자동 삽입하지 않습니다.
- 중심선 계산에는 실행 중인 Docker와 기존 `python:3.11-slim` 이미지, Lanelet2 Python 의존성이 필요합니다. `LANELET_NATIVE_DEPS`로 의존성 디렉터리를 지정할 수 있으며 기본값은 `/private/tmp/morai-lanelet2-20260926/work/native_deps`입니다. 계산 컨테이너는 네트워크 없이 읽기 전용 마운트로 실행합니다.
- 원본 중심선은 편집 후에도 출처 참고선입니다. 경계 보간 중심선은 화면 참고선으로 Lanelet2 native 중심선과 같지 않을 수 있으며 OSM에 자동 삽입하지 않습니다.
- 3D는 실제 XYZ와 높이 1배를 사용합니다. 위성 배경은 **Z=0 참고 평면**이고 도로 메시와 Lanelet은 원본 높이입니다. 원본 수직 datum은 미지정입니다. 편집 도구는 2D로 전환합니다.
- XY 스냅은 좌표만 맞춥니다. 실제 연결에는 **점 ID 합치기** 또는 **공유 경계 지정**을 사용하세요. 같은 좌표에 서로 다른 점 ID가 있을 수 있습니다.
- successor는 좌우 끝점 ID 일치, 이웃은 공유 way ID로 계산합니다. 실제 통행 가능 차선 변경·교통 규칙의 완전한 Lanelet2 routing graph 검증은 별도입니다.
- `mgeo:*` 태그는 출처 기록입니다. 분할·연장·복제 후 원본 station 값이 현재 형상의 길이를 나타내지는 않습니다. 편집 후에는 실제 기하 수치를 확인하세요.
- 교차로와 합류부의 면 중첩은 실제 기하 사실로 표시합니다. 2D 중첩만으로 충돌·교통 오류를 단정하지 않습니다.
- 안전한 자동 편집을 보장할 수 없는 분할(너무 짧은 경계, 다중 교차, 반대 방향 공유, 명시 centerline/상위 relation 등)은 원본을 유지하고 이유를 표시합니다.
